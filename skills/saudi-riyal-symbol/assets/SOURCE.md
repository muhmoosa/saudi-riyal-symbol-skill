# Sources

- `sama-riyal-symbol.svg` — official vector file of the Saudi Riyal symbol, Saudi Central Bank (SAMA). Unmodified (original name `Saudi_Riyal_Symbol-2.svg`).
- `sama-riyal-symbol.png` — official raster file, 3000 × 3353 px, as published by SAMA. Unmodified.
- `sar-symbol.otf` — built from `sama-riyal-symbol.svg` with `scripts/sar_font.py --height 700`: one glyph, U+20C1, the official outline scaled uniformly to 0.70 em. sha256 of this bundled file: `cd8682557cd21564380e2c4c7c76f3164b740336fd29f21e9c06757dbc94180d` (a rebuild has the same glyph but a new timestamp, so a different checksum).
- SAMA also publishes an EPS (`Saudi_Riyal_Symbol-3.eps`) for print and design tools; it is not bundled here.
- Usage rules: SAMA, «دليل استخدام رمز الريال السعودي», pp. 16–17 — https://www.sama.gov.sa/ar-sa/Currency/SRS/Documents/Guidelines.pdf
